# aquila-c4

Documentation rules: [`core/docs.md`](../../core/docs.md).

1. **Mode**: create (no `docs/c4/` yet), update (code/layer change) or review. Ask only if not obvious.
   Creating or reviewing everything reads the codebase → first,
   [`core/tokens.md`](../../core/tokens.md) § High-consumption warning; updating reads only what changed.
2. **Read before drawing**: top-level features/folders, entry points (app shell, routes/pages), backend
   APIs and external SDKs (auth, analytics, payments), client storage and state stores, hosting/CDN. Nothing invented: whatever the
   code does not confirm is marked "to confirm".
3. **Levels** (one file each, Mermaid `C4Context`/`C4Container`/`C4Component`):
   `c4-level-1-context.md` · `c4-level-2-containers.md` · `c4-level-3-<container>.md`; level 4 (code)
   only generated by script, never by hand.
4. Each element has a name, technology and a one-sentence responsibility; each relation has a verb and
   protocol.
5. Update the `docs/c4/README.md` index and link it from `docs/ai/CONTEXT.md` (map).
6. Validate: `npx aquila-react-ai check`; incremental — propose, the dev validates, iterate.
