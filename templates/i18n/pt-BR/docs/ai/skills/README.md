# Skills de domínio do projeto

Uma pasta por skill (`<nome>/SKILL.md` no formato Agent Skills: frontmatter `name` + `description`,
corpo curto, `references/` lidas sob demanda). Fonte única: aqui — **não é copiada nem linkada** para
`.agents/`/`.claude/`. O mapa [`CONTEXT.md`](../CONTEXT.md) diz quando abrir cada uma (ex.: "criar ou
alterar uma funcionalidade → `docs/ai/skills/<nome>/SKILL.md`"), o que funciona igual em qualquer ferramenta.

Use para conhecimento operacional do domínio ("como fazer X sem quebrar nada"); o método
(plano, teste, revisão) já vem do aquila-react-ai.
