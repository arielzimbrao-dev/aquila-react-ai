# Project domain skills

One folder per skill (`<name>/SKILL.md` in Agent Skills format: `name` + `description` frontmatter,
short body, `references/` read on demand). Single source: here — **not copied or linked** to
`.agents/`/`.claude/`. The [`CONTEXT.md`](../CONTEXT.md) map says when to open each one (e.g.: "build
or change a feature → `docs/ai/skills/<name>/SKILL.md`"), which works the same in any tool.

Use them for operational domain knowledge ("how to build X without breaking anything"); the method
(plan, test, review) already comes from aquila-react-ai.
